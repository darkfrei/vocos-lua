## 1. Что это вообще такое

Представьте, что звук можно нарисовать. Не как волну на экране, а как картинку: по горизонтали идёт время, по вертикали — высота звука (низкие звуки внизу, высокие вверху), а яркость точки показывает, насколько громко в этот момент звучит эта высота. Такая картинка называется **спектрограмма**. Если ещё и «сжать» высоты так, как их слышит человеческое ухо (низкие различаем тоньше, высокие грубее), получится **мел-спектрограмма**, или просто «мел». Это слово не нужно запоминать — достаточно знать: **мел — это рисунок звука**.

Многие программы, которые умеют говорить (синтезаторы речи), работают в два шага:

1. Сначала по тексту «рисуют» мел: что и как должно прозвучать.
2. Потом специальная программа превращает рисунок обратно в настоящий звук, который можно слушать.

Вот эта вторая программа и называется **вокодер**. А **Vocos** — имя конкретного вокодера, придуманного исследователями. Он хорошо работает и довольно быстрый.

**Эта библиотека — готовый Vocos, написанный на языке Lua.** Вы даёте ей рисунок звука — она возвращает звук.

### Зачем это нужно

Автор написал её для своей компьютерной игры, где персонажи должны говорить синтезированным голосом. Обычно для запуска нейросетей нужны тяжёлые сторонние программы. Здесь всё сделано так, чтобы **ничего лишнего не требовалось**: один маленький интерпретатор и один файл с обученной сетью.

## 2. Словарик (на всякий случай)

| Слово | Что это простыми словами |
|---|---|
| **Нейросеть** | Большая таблица чисел («весов»), которая что-то умеет: например, превращать рисунок звука в звук. Числа подобрали заранее, обучая сеть на огромном количестве записей. |
| **Вокодер** | Нейросеть, которая превращает «рисунок звука» (мел) в сам звук. |
| **Мел-спектрограмма** | Рисунок звука: время × высота × громкость. |
| **ONNX** (читается «оннкс») | Название формата файла, в котором хранят обученные нейросети. Как .mp3 для музыки или .docx для текста, только для нейросетей. Файл с таблицей чисел. |
| **Lua** (читается «луа») | Простой язык программирования. На нём пишут скрипты в играх. |
| **LuaJIT** | Очень быстрая версия Lua. Это маленькая программа, которая «исполняет» текст на Lua. |
| **LÖVE** (читается «лёве») | Бесплатный движок для 2D-игр. LuaJIT уже встроен в него. |
| **GitHub** | Сайт, где люди хранят и выкладывают исходные тексты программ, чтобы другие могли их скачать, посмотреть и улучшить. |
| **Репозиторий** | «Папка проекта» на GitHub. Внутри — все файлы проекта и история их изменений. |
| **Скрипт** | Небольшая программа в виде текстового файла. |
| **Командная строка** | Чёрное окошко, в котором вместо мыши печатают команды. Страшнее выглядит, чем есть на самом деле. |
| **WAV** | Простой формат звукового файла без сжатия. Открывается любым плеером. |

## 3. Что понадобится

1. **Компьютер** с Windows, Linux или macOS. (Телефон не подойдёт: нужна командная строка и запуск программ.)
2. **LuaJIT** — программа, которая запускает скрипты. Про то, где её взять, ниже.
3. **Эта папка** (проект `vocos-lua`) — вы её уже скачали.
4. **Файл нейросети** `vocos-22khz-univ.onnx`, размер 54 мегабайта. В самом проекте его нет — его выложили отдельно авторы модели. Ссылка в разделе 5.
5. **Любая запись голоса** в формате WAV для проверки (можно записать себя на диктофон телефона и перевести в WAV, или взять любой WAV-файл).

Видеокарта не нужна. Интернет нужен только чтобы скачать файлы.

## 5. Как поставить всё нужное

### Шаг 1. LuaJIT

**Windows.** Самый простой способ — скачать готовый `luajit.exe`. Найдите в интернете «LuaJIT Windows binary» (бывают сборки на GitHub в разделе Releases или на сайте LÖVE). Положите `luajit.exe` в ту же папку, где лежит проект (рядом с папкой `vocos`). Тогда ничего больше настраивать не придётся.

**Linux.** В терминале: `sudo apt install luajit` (Ubuntu/Debian).

**macOS.** В терминале: `brew install luajit`.

Проверка: откройте командную строку в папке проекта и напечатайте

```
luajit -v
```

Должна появиться строчка вроде `LuaJIT 2.1.0-beta3 ...`. Если появилась — всё хорошо.

> **Как открыть командную строку в нужной папке на Windows:** откройте папку проекта в проводнике, щёлкните по адресной строке сверху, сотрите всё, напечатайте `cmd` и нажмите Enter. Откроется чёрное окно уже в нужной папке.

### Шаг 2. Файл нейросети

Скачайте файл по этой ссылке (откроется загрузка на 54 МБ):

```
https://github.com/k2-fsa/sherpa-onnx/releases/download/vocoder-models/vocos-22khz-univ.onnx
```

Положите его **в папку проекта**, рядом с `README.md`. Имя не меняйте: `vocos-22khz-univ.onnx`.

Что это за файл: это обученная нейросеть Vocos в формате ONNX (авторы — BSC-LT, лицензия Apache-2.0, в формат ONNX её перевела команда k2-fsa). Внутри только числа. «Голос» в ней не зашит — какой голос услышите, зависит от того, какую запись вы дадите на вход.

## 6. Первый запуск: пропустим запись через нейросеть

Положите в папку проекта любую запись речи под именем `in.wav` и в командной строке напечатайте:

```
luajit examples/resynth.lua vocos-22khz-univ.onnx in.wav out.wav
```

Что при этом происходит, по шагам:

1. Программа читает вашу запись и при необходимости приводит её к нужной частоте (22 050 отсчётов в секунду) и делает из неё моно.
2. Рисует «картинку звука» (мел).
3. Нейросеть превращает картинку обратно в звук.
4. Результат записывается в `out.wav`.

Откройте `out.wav` любым плеером. Он должен звучать **почти как оригинал**, с лёгкой «цифровостью». Это нормально: звук прошёл через картинку и обратно, а картинка не хранит всех подробностей.

В конце программа напишет число — «разница мелов». Это насколько рисунок получившегося звука отличается от рисунка исходного. У нормальной чистой речи это примерно **0,18–0,19**. Чем меньше — тем точнее. Если число сильно больше (скажем, 0,5 и выше) — скорее всего, в записи шум, музыка, очень тихий голос или вообще не речь.

**Скорость:** примерно секунда работы на секунду звука на одном ядре обычного процессора. То есть запись в 10 секунд обработается за 10 секунд. Это нормально — видеокарта не используется.

## 7. Если вы хотите вставить это в свою программу

Минимальный пример на Lua:

```lua
package.path = "путь/к/vocos-lua/?.lua;путь/к/vocos-lua/?/init.lua;" .. package.path
local vocos = require("vocos")

local v = vocos.load("vocos-22khz-univ.onnx")

local x, n = vocos.wav.read_mono("in.wav")
local mel, F = vocos.mel(x, n)          -- рисунок звука
local y, count = v:synth(mel, F)        -- звук из рисунка
vocos.wav.write("out.wav", y, count, 22050)
```

Если у вас есть своя программа, которая рисует мел по тексту (синтезатор речи), отдавайте мел сюда: массив из `80 × F` чисел (80 полос высоты, F отрезков времени), логарифм громкости. Подробности — в английском README, раздел Use.

## 8. Как сделать файл поменьше

Файл 54 МБ — это много для игры. Библиотека умеет пересохранить нейросеть в своём формате `.vocos` в два раза компактнее (27 МБ), при этом **звук остаётся тем же**:

```
luajit examples/convert.lua vocos-22khz-univ.onnx vocos.vocos f16
```

Дальше можно загружать `vocos.vocos` вместо `.onnx` — всё остальное не меняется.

Есть и более смелый способ: оставить только те «нейроны», которые нужны вашему голосу. Как это делается — в английском README, раздел «Smaller for one voice». Если оставить 1024 из 1536, звук слегка ухудшается (разница 0,24 вместо 0,19); если меньше — заметно хуже. Чтобы резать сильнее, сеть надо **доучивать** — это уже за пределами этой библиотеки.

## 9. Проверка: всё ли работает правильно

```
luajit tests/test.lua
```

В конце должна появиться строка `all tests passed` (все проверки пройдены). Если у вас есть файл нейросети, можно проверить ещё и точное совпадение с «эталоном» (официальной программой ONNX Runtime):

Windows:

```
set VOCOS=vocos-22khz-univ.onnx
luajit tests/test.lua
```

Linux / macOS:

```
VOCOS=vocos-22khz-univ.onnx luajit tests/test.lua
```

Тогда добавится строчка о совпадении с ONNX Runtime (расхождение порядка одной стотысячной).

## 10. Частые вопросы и неполадки

**«luajit» не является внутренней или внешней командой.**
Windows не нашёл программу. Положите `luajit.exe` в папку проекта (рядом с `README.md`) и запускайте команду из этой папки.

**cannot open vocos-22khz-univ.onnx / No such file.**
Файл нейросети не скачан или лежит в другом месте. Он должен быть в папке проекта, а команду надо запускать из этой же папки.

**Выходной звук тихий или с хрипом.**
Проверьте входную запись: нужна чистая речь без музыки. Очень тихие и очень шумные записи вокодер не любит.

**Звук «металлический» или «роботный».**
Немного цифровой окраски в Vocos есть всегда — это особенность метода. Для речи в игре её обычно достаточно.

**Работает медленно.**
Около секунды на секунду звука — норма. Для игры синтезируйте фразу заранее, в отдельном потоке (в LÖVE это `love.thread`), а не в тот момент, когда она нужна.

**Можно ли им пользоваться бесплатно, в том числе в коммерческой игре?**
Код библиотеки — под лицензией MIT: можно использовать, менять и включать в свои проекты, сохранив пометку об авторстве (файл `LICENSE`). Сама нейросеть — не часть этого репозитория, у неё своя лицензия Apache-2.0, она тоже разрешает свободное использование. Это не юридическая консультация: если проект серьёзный, прочитайте обе лицензии сами.

**Это синтезатор речи, который читает текст вслух?**
Нет. Это только вторая половина цепочки: из «рисунка звука» в звук. Чтобы говорить по тексту, нужна ещё первая половина — программа, которая по тексту рисует этот рисунок. Здесь её нет.
